Essência da solução: hash local do arquivo, recibo exportável e verificação posterior. Preparada para ancoragem em blockchain.

1) Calcular hash do arquivo

O que é isso?

Calculamos o SHA-256 localmente no seu navegador. O arquivo não é enviado para nenhum servidor. Esse hash é a “impressão digital” do arquivo.

2) Emitir recibo (JSON)

O recibo contém: algoritmo, hash, nome/tamanho do arquivo, carimbo de data/hora (ISO), emissor e uma ID local.
